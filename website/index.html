Installation

Install in five steps

About ten minutes on a Windows PC with Revit. Every command below has a copy button.

Autodesk Revit2021 – 2027
pyRevit4.8+ or 5.x, with Routes
Python 3.11+ & uvinstall uv
ClaudeDesktop or Claude Code
  1. 1

    Install the extension

    In PowerShell, clone RVTSS into your pyRevit extensions folder. The folder name must end in .extension.

    Keep only one copy. Remove or disable any older Revit MCP extension (for example revit-mcp-python.extension) first, or the two will conflict.

    PowerShell
    cd "$env:APPDATA\pyRevit\Extensions"
git clone https://github.com/souhaibsmadi42/RVTSS_MCP RVTSS.extension
  2. 2

    Turn on pyRevit Routes

    In Revit: pyRevit tab → Settings → Routes. Enable Routes Server, set the host to 127.0.0.1, keep port 48884, then Save Settings and Reload.

    A new RVTSS tab appears in the ribbon.

    Routes settings
    Routes Server   ON
Host            127.0.0.1
Port            48884
  3. 3

    Check the server

    Open the status page in a browser while Revit is running. You should see "health": "healthy" and the RVTSS version.

    If it says Route does not exits, enable the extension in pyRevit → Extensions → RVTSS, then restart Revit.

    Browser
    http://127.0.0.1:48884/revit_mcp/status/
    Expected
    { "status": "active", "health": "healthy",
  "rvtss_version": "2.1.0", "api_name": "revit_mcp" }
  4. 4

    Run the self-test

    On the RVTSS tab click Diagnostics → Run Self-Test. It works on a copy of the bundled test model and opens a pass/fail report. Your own files are never touched.

    Report written to
    %TEMP%\RVTSS_live\rvtss_live_report.md
  5. 5

    Connect Claude

    Install the dependencies with uv sync. Then register the MCP server in Claude Desktop (Settings → Developer → Edit Config) or with one Claude Code command.

    Restart Claude. The RVTSS tools appear, and you can ask: “Call get_session_info and tell me which model is open.”

    PowerShell
    cd "$env:APPDATA\pyRevit\Extensions\RVTSS.extension"
uv sync
    claude_desktop_config.json · replace <you>
    {
  "mcpServers": {
    "RVTSS Revit": {
      "command": "uv",
      "args": [
        "run", "--project", "C:\\Users\\<you>\\AppData\\Roaming\\pyRevit\\Extensions\\RVTSS.extension",
        "python", "C:\\Users\\<you>\\AppData\\Roaming\\pyRevit\\Extensions\\RVTSS.extension\\main.py"
      ],
      "env": { "RVTSS_TOOLSETS": "bim_coordinator" }
    }
  }
}
    PowerShell
    claude mcp add -s user RVTSS -- uv run --project "$env:APPDATA\pyRevit\Extensions\RVTSS.extension" python "$env:APPDATA\pyRevit\Extensions\RVTSS.extension\main.py"

Safety model

Built to be safe

  • TransactionsEvery change is named and can be undone in Revit. Errors roll back.
  • Dry runsRevit validates the whole change, then rolls it back.
  • ConfirmationDeletions, imports, renames and edits over 100 elements show a preview first.
  • Units required“900 mm”, never a bare 900. No feet/millimetre mix-ups.
  • Lock it downBind Routes to 127.0.0.1, add an RVTSS_TOKEN, or disable code execution.
Troubleshooting

If something's off

“Route does not exits” or no RVTSS tab

The extension is disabled. In Revit: pyRevit → Extensions → RVTSS → Enable, then restart Revit. Check that the folder name ends in .extension.

Claude doesn't show the RVTSS tools

Fully quit Claude Desktop and start it again. If uv isn't found, put its full path in "command", for example C:\\Users\\<you>\\.local\\bin\\uv.exe. Check both paths in args.

“Revit is busy”

Close any open dialog in Revit and finish edit modes (sketch, group or family edit), then ask again. For very large models, raise RVTSS_TIMEOUT.

Revit runs in a VM

Set REVIT_HOST to the VM's address and RVTSS_ALLOW_REMOTE=1 in the server's env. Add an RVTSS_TOKEN too.
